화해중재 갈등분석 도구 — 사용 방법
====================================================

1단계. 사안 개요
--------------------------------
- 사안명, 학교/학년-반, 작성자, 사안 경위를 입력합니다.
- 화면 위쪽 "가상 사례로 미리 살펴보기"에서 예시 3종(신체적 다툼·
  사이버폭력·강요)을 눌러보면 전체 흐름을 바로 확인할 수 있습니다.

- "① 요청문 만들기" 클릭 → "복사하기" 클릭
- 그 내용을 Claude 대화창(또는 사용중인 AI)에 붙여넣고 전송
- Claude가 준 답변을 전체 복사해서 "② 결과 반영하기" 칸에 붙여넣고 클릭
  → 회복적 질문(사건이해/영향확인/피해회복/재발방지)과
    사전 학생 인터뷰지(피해 관련/가해 관련)가 자동으로 정리됩니다.
- 인터뷰지는 "인터뷰지 인쇄" 버튼으로 출력해 예비중재 전 학생에게
  배부할 수 있습니다.

2단계. 예비중재에서 들은 이야기 입력
--------------------------------
- 당사자(학생·보호자)별로 예비중재에서 나눈 이야기를 입력합니다.
- 1단계와 동일하게 "요청문 만들기 → Claude(또는 사용중인 AI)에 붙여넣기 →
  결과 반영하기" 순서로 진행하면, 새 창(오버레이) 형태로
  갈등분석보고서(양파기법: 입장·실익·욕구 분석)가 열립니다.
- 보고서 내용은 클릭해서 바로 수정할 수 있습니다.

3단계. 화해중재 합의문 만들기
--------------------------------
- 보고서 화면 하단의 "① 합의문 요청문 만들기" → 복사 →
  Claude(또는 사용중인 AI) 대화창에 붙여넣기 → 답변을 "② 결과 반영하기"에 붙여넣으면
  "화해중재 합의문(약속이행문)"과 "우리들의 약속" 두 문서가
  탭으로 추가됩니다. 역시 클릭해서 수정 가능합니다.
- 상단 "인쇄/PDF" 버튼으로 각 문서를 인쇄하거나 PDF로 저장할 수
  있습니다.

참고
--------------------------------
- 이 앱은 자체적으로 AI API를 호출하지 않습니다. 반드시 Claude(또는 사용중인 AI)
  대화창을 통해 답변을 받아 붙여넣어야 합니다.
- "가상 사례로 미리 살펴보기"는 인터넷 연결 없이도 바로 작동합니다.
- 수정이나 기능 추가가 필요하면 Claude(또는 사용중인 AI)와의 대화에서 요청해 주세요.
