화해중재 갈등분석 도구 — 웹앱(PWA)으로 설치하기
====================================================

이 폴더에는 휴대폰/PC 홈화면에 아이콘으로 설치해서 쓸 수 있는
웹앱(PWA) 파일이 들어 있습니다.

⚠ 중요: 이 파일들을 그냥 더블클릭해서 열면(주소창이 file://로 시작하면)
브라우저 보안 정책 때문에 "설치" 버튼이 나타나지 않습니다.
아래 방법 중 하나로 인터넷에 올린 뒤(무료, 코딩 지식 불필요) 그 주소로
접속해야 설치가 가능합니다.

────────────────────────────────────────
방법 A. Netlify Drop (가장 쉬움, 5분, 회원가입 불필요)
────────────────────────────────────────
1. 브라우저에서 https://app.netlify.com/drop 접속
2. 이 폴더(app 폴더) 전체를 화면 가운데로 드래그 앤 드롭
3. 잠시 후 "https://무작위이름.netlify.app" 같은 주소가 생성됩니다
4. 그 주소를 휴대폰 브라우저(Chrome/Safari)로 접속
5. Android(Chrome): 우측 상단 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
   iOS(Safari): 하단 공유 버튼 → "홈 화면에 추가"
6. 홈 화면에 아이콘이 생기고, 눌러서 열면 브라우저 주소창 없이
   앱처럼 전체 화면으로 실행됩니다.

나중에 주소를 계속 쓰고 싶다면, 같은 화면에서 무료 계정을 만들어
사이트를 "Claim"하면 주소가 영구적으로 유지됩니다.

────────────────────────────────────────
방법 B. GitHub Pages (GitHub 계정이 있는 경우)
────────────────────────────────────────
1. github.com에서 새 저장소(Repository) 생성
2. 이 폴더 안의 파일들(index.html, manifest.json, sw.js, icons 폴더)을
   저장소에 업로드(Add file → Upload files)
3. 저장소 Settings → Pages → Branch를 main으로 설정 후 저장
4. 몇 분 후 https://아이디.github.io/저장소이름/ 주소가 생성됩니다
5. 위 방법 A의 5~6번과 동일하게 휴대폰에서 접속 후 홈 화면에 추가

────────────────────────────────────────
방법 C. 학교 자체 웹 서버가 있는 경우
────────────────────────────────────────
이 폴더를 통째로 업로드하기만 하면 됩니다 (index.html이 있는 폴더
그대로). 별도 설정은 필요 없습니다.

────────────────────────────────────────
설치 후 참고사항
────────────────────────────────────────
- 이 앱은 내부적으로 API를 호출하지 않고, "요청문 만들기 → Claude
  대화창에 붙여넣기 → 결과 붙여넣기" 방식으로 동작합니다. 인터넷
  연결이 없어도 입력 화면과 이미 만든 보고서는 계속 볼 수 있습니다.
- 화면 최상단의 "가상 사례로 미리 살펴보기" 버튼은 인터넷 연결 없이도
  바로 작동합니다(내장된 예시 데이터 사용).
- 안드로이드/아이폰 모두 한 번 설치하면 오프라인에서도 앱 화면 자체는
  열립니다(단, "결과 반영하기"에 쓸 Claude 답변을 받으려면 별도로
  Claude 앱이나 웹사이트가 필요합니다).

문의사항이나 수정 요청은 이 대화(Claude)로 다시 요청해 주세요.
